# 📅 Roblox Project Master Schedule

## 🎯 Milestone 1: 第一回プレゼンテーション（8月末）
* **Target Audience:** シンガポール参加者のみ
* **Goal:** 基本情報ボードおよびワールド基本構造の完成

### 📋 Action Items
* [ ] **Information Boards (全面実装)**
  * [ ] Featured Sightseeing Spots Boards (全18箇所)
  * [ ] Specific Spot & Shop Boards (全6箇所)
  * [ ] Accommodations Boards
  * [ ] Restaurants Boards
* [ ] **World Environment (基礎構築)**
  * [ ] 部屋全体の外壁・床の設定
* [ ] **3D Objects & Props (プロトタイプ)**
  * [ ] 3D Environment Objects（試作数点）
  * [ ] Small Prop & Detail Objects（試作数点）

## 🎯 Milestone 2: 第二回プレゼンテーション（9月末）
* **Target Audience:** シンガポール・マレーシア参加者全員
* **Goal:** 3Dオブジェクトの完備、装飾拡張、およびユーザーインタラクション機能の実装

### 📋 Action Items
* [ ] **Interactive System (インタラクション機能)**
  * [ ] 意見書き込みチャットボックスの実装
  * [ ] 食べたいもの等の投票ボックス機能の実装
* [ ] **3D Environment Objects (全モデル完成)**
  * [ ] Iconic Major Landmarks (歌舞伎町アーチ、センター街看板、竹下通りゲート、三越ファサード、雷門、東京タワー)
* [ ] **Small Prop & Detail Objects (全モデル完成)**
  * [ ] 寿司・原宿クレープ等の小物プロップ
  * [ ] ゴジラヘッド・3D巨大猫 (オプション実装)
* [ ] **World Environment (完成度向上)**
  * [ ] 部屋の装飾拡張およびライティング調整
