# Blender Lantern UV Mapping Correction & Workflow Learning & Development Log

Blenderを用いたユリカモメオブジェクト（Prop_Seagul）の制作において、効率的に構成パーツを作成した学習記録です。

使用環境：
- Blender 5.2.2 LTS / Windows
- Roblox Studio（エクスポート対象環境）
- 目的：東京プレゼン用ワールド（Roblox）に配置するユリカモメアセットの構築
- 制作対象：Prop_Dinosaur

## 🧩 基本メッシュ・パーツ構成とモデリング手法

ローポリゴンのユリカモメの胴体や各部位オブジェクトを作成する際のデザインおよび複製・変形の基本手順です。

1. 1つのオブジェクトにまとめる手順
- 両方のオブジェクトを選択する: オブジェクトモードの状態で、キーボードの Shift キーを押しながら「足先のオブジェクト」と「足のシリンダー」の両方を順番にクリックして選択します（右側の画面（アウトライナー）で両方が青くハイライトされていればOKです）。
- 結合する: キーボードの Ctrl + J キーを押します。

2. プロポショナル編集を使ってアーチ形を作る手順
- プロポショナル編集をオンにする: 3Dビューポートの画面上部中央にある、丸いアイコン（プロポショナル編集のボタン）をクリックして有効にします（または、キーボードの O キーを押してもON/OFFできます）。（※隣のドロップダウンはスムーズを選んでおくと綺麗に曲がります）
- 一番上の頂点を選んで持ち上げる: 頂点選択モード（キーボードの 1）にします。一番上の中央にある頂点（または、上端の辺）を1つだけクリックして選択します。G キーを押して、続けて Z キーを押します。そのままマウスを上に動かすと、選択した頂点だけでなく、周囲の頂点も巻き込んでなだらかに持ち上がり、綺麗なアーチ形になります。

3. 左右対称にオブジェクトの複製と移動を行う手順
- オブジェクトを選択する: アウトライナーまたは3Dビューポートで Eye_Right が選択されている状態にします。
- 複製する: ショートカットキー Shift + D を押し、そのまま Enter または右クリックを押して、位置を動かさずにその場で複製します。
- 原点の確認: このモデルがワールドの中心（X軸の真ん中）を基準に作られている場合、そのままミラー反転が使えます。もしオブジェクトの原点がモデルの中心からズレている場合は、上のメニューの [オブジェクト] ＞ [原点を設定] ＞ [3Dカーソルへ原点を移動] などで、シーンの中心（X=0）を原点にしておくと反転しやすくなります。
- 反対側に反転させる: 複製した状態で、上のメニューの [オブジェクト] ＞ [ミラー] ＞ [グローバル X] を選択します。（※または、ショートカット S ➔ X ➔ -1 と入力してエンターを押しても、X軸方向に反転できます）

4. 一括で100分の1にする手順
- すべてのオブジェクトを選択する: 3Dビューポート上で A キー を押して、シーン内のすべてのオブジェクトを選択状態にします。事前に全オブジェクトのTransformにあるLocationをロックしておくと、位置関係や中心座標が壊れません。
- スケールを変更する: キーボードの S キー を押します。続いて 0.01 と入力し、Enter キー を押します（またはマウスを動かしてクリックします）。これで、すべてのオブジェクトの大きさが一括して100分の1になります。


## 📋 学習項目および設定パラメータ一覧

| 区分 | 項目 / ノード | 設定値 / 操作 | 目的・効果 |
|---|---|---|---|
| Modeling | Join Objects | 複数選択して Ctrl + J | 複数メッシュを1つのオブジェクトへ結合 |
| Modeling | Proportional Editing | O キー ON / Smooth / G ➔ Z 操作 | 周囲の頂点を巻き込んだなだらかなアーチ形状の変形 |
| Modeling | Duplicate & Mirror | Shift + D ➔ オブジェクト・ミラー (グローバル X) | 左右対称の位置へのパーツ複製と反転配置 |
| Modeling | Batch Scale | A キー ➔ S ➔ 0.01 ➔ Enter (Location Lock推奨) | シーン内全オブジェクトのサイズの一括縮小 |
