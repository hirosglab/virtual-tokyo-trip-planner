# Blender to Roblox Export & Scale Workflow Learning & Development Log

Blenderで制作した3Dモデル（トロ握り寿司）を、スケール・トランスフォームの不整合なくRoblox Studioへ意図した原寸大（`Scale = 1.0`）で正常インポートするための設定手順、スケール設計理論、およびトラブルシューティングの学習記録です。

使用環境：
- Blender 5.2.2 LTS / Windows
- Roblox Studio
- 目的：築地プレゼン用ワールド（Roblox）に配置する寿司アセットの標準化インポートプロセスの確立
- 制作対象：`Sushi_Toro_Model`（`Sushi_Rice` / `Sushi_Toro`）

---

## 📌 概要とスケール設計理論

Blender（メートル単位系 `Meters`）とRoblox Studio（`Studs` 単位系）の間で発生する倍率のギャップを解消し、インポート時に手動でスケール数値を調整（`0.1` や `0.005` などへの変更）することなく、**最初から `Scale = 1.0` で完璧な表示サイズ（横幅 約 0.2 studs / 6cm）** を実現するための計算モデルです。

### 単位換算の基準値
* **Roblox 1 Stud** \(\approx\) **`0.28 m`** (28cm)
* **実物大の握り寿司（目標サイズ）**: 横幅 約 `6 cm`（`0.06 m`） \(\approx\) **約 `0.214 Studs`**

### スケール設計の移行経緯

| エクスポート回 | Blender側の設定寸法 (`Dimensions X`) | FBX Export Scale | Robloxインポート結果 (`Scale`) | 発生した現象と要因 |
|---|---|---|---|---|
| **1回目（巨大化）** | `2.29 m` （トランスフォーム未適用） | `1.0` | `1.0` (巨大) | スケール未適用により巨大モデルとして配置された。 |
| **2回目（縮小試行）** | `0.611 m` (約61cm) | `0.01` (1/100) | `1.0` (極小/見えず) | `0.611m × 0.01 = 0.006m`（約6mm）の米粒以下となり消失。 |
| **3回目（手動調整）** | `0.611 m` (約61cm) | `1.0` | `0.1` (手動変更) | Roblox側で `Scale = 0.1` に手動縮小することで適正サイズに整合。 |
| **4回目（空インポート）** | - | - | - | Blenderエクスポート時にオブジェクト非選択のため空グループが出力。 |
| **最終確立（目標達成）** | **`0.061 m` (約6.1cm)** | **`1.0`** | **`1.0` (手動変更なし)** | **Blender寸法を実寸化し `1.0` 出力で完全に一致。** |

## 🔍 Blender側の寸法設定とトランスフォーム適用

Robloxで `Scale = 1.0` インポートを完了させるための、Blender側での最終的なトランスフォーム調整手順です。

### 1. 寸法（Dimensions）の最終実寸設定
1. オブジェクトモード（`Object Mode`）で該当パーツを選択。
2. **`N` キー** を押して右サイドバーを表示し、**`Item` ➔ `Dimensions`** を以下の実寸値に書き換え：

* **`Sushi_Rice`（シャリ）**
  * **X**: `0.059 m`（5.9 cm）
  * **Y**: `0.031 m`（3.1 cm）
  * **Z**: `0.028 m`（2.8 cm）

* **`Sushi_Toro`（トロ）**
  * **X**: `0.061 m`（6.1 cm）
  * **Y**: `0.032 m`（3.2 cm）
  * **Z**: `0.013 m`（1.3 cm）

### 2. 全トランスフォームの確定（Apply All Transforms）
1. 3Dビューポート上で **`A` キー** を押し、`Sushi_Rice` と `Sushi_Toro` の両方を全選択。
2. ショートカット **`Ctrl + A` ➔ `All Transforms`** を実行。
3. `Scale` の数値が **`(X: 1.000, Y: 1.000, Z: 1.000)`** に初期化・固定されたことを確認。

## ⚙️ FBXエクスポートの完全手順（チェックリスト）

BlenderからRoblox Studioへ持ち出す際、パーツ欠損や極小化を防ぐエクスポート詳細設定です。

1. **オブジェクトの選択**: 3Dビューポートで **`A` キー** を押し、出力したいメッシュをすべて全選択（オレンジ色の枠線）。
2. **メニュー**: 上部 **`File` ➔ `Export` ➔ `FBX (.fbx)`** を選択。
3. **右側設定パネルの必須パラメータ設定**:
```
 [ FBX Export Settings ]
 ├── Include
 │    ├── Selected Objects ───── [ ON ] (選択オブジェクトのみ出力)
 │    └── Object Types ───────── [ Mesh ] (メッシュのみに限定)
 ├── Transform
 │    ├── Scale ──────────────── [ 1.00 ] (1.0倍のまま出力)
 │    ├── Apply Scalings ─────── [ All Local ]
 │    └── Forward / Up ───────── [ -Y Forward / Z Up ]
 └── Geometry
      └── Apply Modifiers ────── [ ON ] (Bevel等をメッシュ化)
```
4. **テクスチャ埋め込み設定（画像適用時）**:
   * **`Path Mode`**: **`Copy`**
   * **`Embed Textures`（箱アイコン）**: **オン（白く点灯）**

## 🚀 Roblox Studio インポートとトラブルシューティング

### 1. 3D Importer によるインポート
1. Roblox Studioの上部リボンから **`Home` ➔ `3D Importer`** を選択。
2. 出力した FBX ファイルを選択し、そのまま `Import` を実行。

### 2. トラブルシューティング：モデルが見えない・フォーカス（F）できない現象
インポート直後にモデルが見えなくなり、`F` キーを押してもカメラが寄らない場合のチェックフローです。

```
 [ インポート後の異常検知 ]
       │
       ├─▶ エクスプローラーの `▶` マークを確認
       │     ├─ `▶` がない場合 ───▶ 中身が空（Blenderでオブジェクト非選択でエクスポートされた）
       │     └─ `▶` がある場合 ───▶ 子パーツ（MeshPart）が存在する
       │
       └─▶ プロパティ（Properties）の数値確認
             ├─ `Scale` が `0.001` 等 ──▶ 手動で `10` 等にして位置確認
             └─ `Position` の値 ────────▶ プレイヤーから遥か遠くに配置されている
```
* **解決策**:
  * 子パーツが存在しない場合は、Blender側で **`A`（全選択）** を確認し、`Selected Objects` オプションをオンにして再エクスポートする。
  * サイズが極小になっている場合は、Blender側の `Dimensions` 設定およびエクスポート時の `Scale = 1.0` 設定を見直す。

## 📋 学習項目およびエクスポートパラメータ一覧

| 区分 | 項目 / パラメータ | 設定値 / 操作 | 目的・効果 |
|---|---|---|---|
| Blender | 寸法指定 (Dimensions) | X: 0.061m / Y: 0.032m | 実物大の寿司サイズ（約6cm）へのリサイズ |
| Blender | トランスフォーム適用 | `Ctrl + A` ➔ `All Transforms` | スケール倍率を (1,1,1) の基準値に確定 |
| FBX Export | Selected Objects | ON | 選択したメッシュのみを正確に抽出して出力 |
| FBX Export | Scale | 1.00 | 変形倍率をかけずに1:1のスケールで書き出し |
| FBX Export | Apply Modifiers | ON | Bevelなどのモディファイアを確定してメッシュ化 |
| FBX Export | Path Mode / Embed | Copy + 箱アイコンON | テクスチャ画像をFBX内部に埋め込み |
| Roblox | 3D Importer | デフォルト設定 | スケール変更なしで `Scale = 1.0` インポート |
| Roblox | Explorer Check | `▶` 内の子メッシュ確認 | モデル構造とメッシュ存在の正常性検証 |
