# Blender Viewport, Origin & Multi-Object Alignment Learning & Development Log

Blenderで制作した寿司オブジェクト（`Sushi_Rice`, `Sushi_Samon`, `Sushi_Nori` 等）の複数パーツにおけるサイズ一括調整、原点（Origin）の適正化、カメラフォーカス操作、およびモディファイアー適用時のトラブルシューティングに関する学習記録です。

使用環境：
- Blender 5.2.2 LTS / Windows
- Roblox Studio
- 目的：Robloxインポート時におけるマルチパーツ（Model）の座標ズレ・テクスチャ混ざり・スケール崩れの防止
- 制作対象：`Sushi_Salmon` / `Sushi_Tamago`（`Sushi_Rice` / `Sushi_Samon` / `Sushi_Nori`）
---
## 📌 複数オブジェクトの位置ズレを防ぐ一括縮小と原点設定手順

Robloxへインポートする際、パーツごとに独立してスケール変更や原点変更を行うと、読み込み時に位置関係が崩れる原因となります。位置関係（相対座標）を維持したまま一括縮小し、共通の原点を設定する標準手順です。

### 1. 全パーツ同時選択による比例縮小
1. 3Dビューポート上で縮小・調整したいパーツ（例：`Sushi_Rice` と `Sushi_Samon`）を両方選択（`Shift` + クリック または `A` キー）。
2. キーボードで **`S` ➔ `0.5` ➔ `Enter`** を入力（位置関係を維持したまま正確に 50% へ縮小）。

### 2. 全トランスフォームの確定（Apply All Transforms）
1. 両方を選択した状態で **`Ctrl + A` ➔ `All Transforms`** を実行。
2. `Scale` が `(X: 1.000, Y: 1.000, Z: 1.000)` にリセットされ、現在の見た目の大きさがオブジェクトの基本形状として固定されたことを確認。

### 3. 原点（Origin）の設定手法とその選定
オブジェクトの中心点（原点 / Pivot）をどこに配置するかによって操作方法を使い分けます。

* **パターンA：メッシュ自体の中心に原点を配置する場合（推奨）**
  1. 対象のオブジェクトを選択。
  2. 上部メニューから **`Object` ➔ `Set Origin` ➔ `Origin to Geometry`** を実行。
  3. 各パーツ（あるいは組み合わせ）の立体としての中心にオレンジ色の原点（ピボット）が自動配置されます。

* **パターンB：ワールド原点 (0, 0, 0) に共通の原点を揃える場合**
  1. **`Shift + C`**（または 3Dカーソルのリセット操作）で 3Dカーソルをワールド中央 `(0, 0, 0)` に配置。
  2. 対象オブジェクトを選択し、**`Object` ➔ `Set Origin` ➔ `Origin to 3D Cursor`** を実行。
  3. 複数パーツの原点が同一座標 `(0,0,0)` に統一され、Robloxインポート時に原点ズレなく重なり合います。

## 🔍 カメラ視点の注視・フォーカス操作（画面いっぱいにジャスト表示）

小さなオブジェクト（数センチクラスの寿司や提灯など）を見失った際、一瞬でカメラの注視点を合わせ、画面中央にフレーム収めする標準操作です。

### 1. アニメーション・作業時のジャストフォーカス
1. 画面右上のアウトライナー（Scene Collection）一覧から、フォーカスしたいオブジェクト（例：`Sushi_Rice`, `Sushi_Tamago`, 提灯）をクリックして選択。
2. キーボードの操作：
   * **テンキーがある場合**: **`.`（ピリオド / テンキー）** を押す。
   * **テンキーがない場合**: 上部メニュー **`View` ➔ `Frame Selected`** を実行。
3. カメラが選択したオブジェクトの直近までジャンプし、画面中央にジャストサイズで拡大表示されます。

### 2. 注意点：`Shift + C` の挙動について
* **機能**: 3Dカーソルをワールド原点 `(0,0,0)` に戻すと同時に、**「シーン全体の全オブジェクトが収まる位置までカメラを引き伸ばす（Frame All）」** 処理が走ります。
* **現象**: シーン内にライトやカメラ、または遠方のオブジェクトが存在する場合、カメラ視点が極端に後退し、小さな寿司オブジェクト（数センチ）が点のように小さくなって見えなくなる原因となります。
* **対処**: 見えなくなった場合は即座にアウトライナーで目的のメッシュを選択し、**`View` ➔ `Frame Selected`（テンキー `.`）** でフォーカスを戻します。

## ⚙️ トラブルシューティング：All Transforms 実行時に特定パーツ（Nori等）が縮む現象

### 1. 発生要因（モディファイアーとスケールの依存性）
`Sushi_Nori` などのパーツに **Solidify（厚み付け）** や **Shrinkwrap**、**Subdivision Surface** などのモディファイアーが未適用（未確定）のまま残っている場合、`Ctrl + A` ➔ `All Transforms`（スケール `0.5` ➔ `1.0` への再計算）を実行すると、モディファイアー側の厚みパラメータが新しいスケール基準で再計算され、見た目の形状や厚みがキュッと小さく縮んでしまう現象が発生します。

### 2. 解決手順（モディファイアーの確定）
1. 画面右側のプロパティパネルから **レンチのマーク（Modifier Properties）** タブを開く。
2. 設定されているモディファイアー（Solidify等）の右側にある **「∨」メニュー ➔ `Apply`** を実行（またはモディファイアー上にカーソルを置いて **`Ctrl + A`**）。
3. モディファイアーがメッシュ構造として完全に確定されたのを確認する。
4. 再度対象オブジェクトを選択し、**`Ctrl + A` ➔ `All Transforms`** を実行する。
   * これにより、見た目の形状・厚みを完全に保持したまま `Scale` を `(1.0, 1.0, 1.0)` へ安全に固定できます。
